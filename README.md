# Orthodox AI Assistant

This repository contains the implementation contract pack for the Patristic Library Assistant.

For coding sessions, read [AGENTS.md](./AGENTS.md) first. It is the only root-level implementation brief and defines the normal read order.

Detailed documentation lives under `docs/`:

- `docs/DOCS_INDEX.md`: documentation map, status, and traceability.
- `docs/contracts/`: compact implementation contracts.
- `docs/adr/`: accepted architecture decision records.
- `docs/api/` and `docs/schemas/`: API and JSON contracts.
- `docs/task_cards/phase1/`: bounded implementation tasks.
- `docs/reference/` and `docs/archive/`: source/reference material not read during normal coding.

Archived PDFs and long planning drafts are retained for traceability only. Newer canonical docs, ADRs, schemas, fixtures, and tests override them.
