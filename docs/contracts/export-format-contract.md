# Export Format Contract

Status: Canonical
Date: 2026-05-19
ADR: 0013, 0014

This document defines the format specifications for PDF, DOCX, and PPTX exports. All exports are produced by certified `ExportProvider` adapters per ADR 0014. Citation footnotes are mandatory in all formats and must be machine-readable.

## Supported Formats

| Format | Extension | MIME type | Provider interface method |
|---|---|---|---|
| PDF | `.pdf` | `application/pdf` | `export(format='pdf')` |
| DOCX | `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | `export(format='docx')` |
| PPTX | `.pptx` | `application/vnd.openxmlformats-officedocument.presentationml.presentation` | `export(format='pptx')` |
| HTML slides | `.html` | `text/html` | `render_slides` (Marp/Reveal.js route) |

## Citation Footnoting

All exported documents must embed citations as structured footnotes. This is verified by `tests/artifacts/test_export_citation_injection.py`.

### Requirements

1. Every factual claim that corresponds to a `citationRef` in the artifact data must have a superscript footnote marker in the body text.
2. Footnotes appear at the bottom of each page (PDF, PPTX) or as endnotes grouped at the end of the document (DOCX).
3. Each footnote contains: source title, author/father name, work name, page/timestamp reference, and a shortened verbatim quote (max 120 chars).
4. Footnotes are tagged with the `chunk_id` in document metadata (not visible in rendered output) for machine-readability and citation export.
5. A "References" or "Sources" section at the end of the document lists all unique sources alphabetically.

### Format-Specific Implementation

**PDF (react-pdf):** Footnotes rendered as `<Text>` elements in a fixed-height footer row per page. `chunk_id` embedded as a PDF custom property on the footnote element.

**DOCX (docx.js):** Footnotes rendered as Word footnote objects (`w:footnote`). `chunk_id` stored as a custom XML part in the document. The References section uses a `Heading2` style named `OrthodoxAI_References`.

**PPTX (pptxgenjs):** Footnotes rendered as a small-font text box in the bottom 10% of each slide. References slide appended at the end of the deck. `chunk_id` stored as a custom shape property.

## Tenant Branding

All exports accept a `TenantBranding` object. Fields:

| Field | Default | Description |
|---|---|---|
| `primaryColor` | `#1a1a2e` (dark navy) | Heading and accent color |
| `secondaryColor` | `#e8e0d0` (parchment) | Background color for header/footer |
| `logoUrl` | Platform logo | Absolute URL to a PNG/SVG (served from platform CDN; not fetched at render time) |
| `fontFamily` | `'Palatino Linotype', serif` | Body text font |
| `headerTemplate` | `'{documentTitle} | {tenantName}'` | Header string; variables: `{documentTitle}`, `{tenantName}`, `{date}` |
| `footerTemplate` | `'© {year} {tenantName} · Generated by Orthodox AI Assistant'` | Footer string |
| `includeWatermark` | `true` | Whether to include the provenance watermark |

The provenance watermark (`Generated by Orthodox AI Assistant · Evidence-grounded · {date}`) is included by default on all exports. It may be suppressed for Enterprise tenants that have `config.suppressWatermark=true`.

## Document Structure Requirements

### PDF — General Documents (Study Packet, Sermon Outline, etc.)

- Page size: A4 (default) or Letter (if `locale` is `en-US`).
- Margins: 25mm top/bottom, 20mm left/right.
- Body font: 11pt serif.
- Headings: H1 = 16pt bold, H2 = 13pt bold, H3 = 11pt bold italic.
- Citation markers: superscript, 8pt.
- Footnotes: 8pt, separated from body by a 0.5pt horizontal rule, max 4 lines per footnote.
- Page numbers: bottom center.
- Table of contents for documents with > 4 sections.

### PDF — Parish Bulletin Insert

- Page size: A5 (half-page format).
- One column, 12mm margins.
- Font: 10pt sans-serif for readability at small size.
- No footnotes; citations appear as inline parenthetical references (Author, Work, Page).
- Target reading level: accessible to non-academic readers.

### DOCX — All Document Types

- Heading styles: `OrthodoxAI_H1`, `OrthodoxAI_H2`, `OrthodoxAI_H3` (custom styles to avoid conflicts with tenant Word templates).
- Custom XML part stores: `artifactId`, `tenantId`, `generatedAt`, `citationRefs` (JSON array), `evidencePacketHash`.
- Compatibility mode: Office 2016+.

### PPTX — Slide Decks

- Slide size: Widescreen 16:9 (default) or Standard 4:3.
- Max 7 bullet points per slide.
- Speaker notes: included by default; suppressible via `generationOptions.includeSpeakerNotes=false`.
- Title slide: document title + tenant name + date.
- Section divider slides for multi-section documents.
- Final slide: "Sources" listing all cited works.
- Custom property on the presentation: `artifactId`, `generatedAt`.

## File Naming Convention

Exported files are named:
```
{artifactType}-{tenantSlug}-{YYYY-MM-DD}.{ext}
```

Examples:
- `study_packet-orthodox_ethos-2026-05-19.pdf`
- `bishop_briefing-thessaloniki_dept-2026-05-20.docx`

## Security

- Exported files must not contain embedded JavaScript (PDF actions, DOCX macros, PPTX VBA). The `ExportProvider` implementation must strip or refuse to generate any scripting elements.
- Logo URLs must resolve to the platform CDN (`cdn.{platform_domain}`); external logo URLs are rejected at branding validation time. This prevents SSRF via tenant-controlled branding.
- File size limit: 50 MB. Generation fails with `artifact_generation_failed` if the export would exceed this limit.

## Forbidden

- Exporting a document with empty or missing citation footnotes.
- Fetching external images or assets at export time (all assets are bundled at ingest time and served from the platform CDN).
- Embedding JavaScript, macros, or executable code in any export format.
- Suppressing the provenance watermark for non-Enterprise tenants.
